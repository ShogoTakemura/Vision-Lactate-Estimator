# 被験者データ基準補正処理

表面correct dataと内骨格データの二種類を計算する.
重心計算の結果向上と同時に, ワイヤフレームや剛体モデルを使用した可視化に繋げる.(より身体動作を明確にする)

## 使用方法

1. correct pickleに処理対象のファイルを格納する.
2. `pipenv run app`コマンドで, modelbased correct poseを選択する.
3. modelbased workset csvを一度更新する
4. subject_id, baseframe_idをconfigに存在するcsvを元にworksetに記載
5. 再度実行し, worksetを更新せず先へ進む(Y or yを選択しなければそのまま)

## 種類

- 周囲径を元にした骨格の補正
- 基準フレームの同定
- 腰, 足首の補正処理
- 補正後姿勢のデータを後処理

### 周囲径を元にした奥行きの補正

手首, 肘, 肩, 頭, 膝の奥行き座標の補正に計測した周囲径を使用する.
断面はすべて円と仮定して, 半径を計算した後にその値を引き算する.
目も奥行き調整する.手首は少し考慮する. そこまで丸くないので.

入力 : セグメントの周囲径, subjectinfoに追加

### 基準フレームの同定

movie3Dの結果から, 基準フレームを抜き出し, それを胴体長さと大腿の長さとして使用する.
→それらの自動化用ツールの作成. というか, ザッピングツールの移植.(frame tool viewer)
ここは, ツールとして独立させる.

入力 : 基準フレーム二つ

### 腰, 足首, 踵の補正処理

腰の補正は, jupyter notebookに実装しているのでそれを参照する.
足首は, 固定点を基準フレームから抜き出し, そこから奥行き調整を行う.
足首自体のAnkleとしての保持は必要だが, 地面に対して相対的に固定される足首関節の位置を決定したい.

入力 : 部位長さオブジェクト. 基準フレームから作成したオブジェクトを使用する.

### 全体のまとめ処理

これらはすべて, Filterとして(ないしツールとして)存在している. よって, コンポーネントとして処理をするTask用のメソッドが必要.
また、correct poseとsegment infoを繋げる処理が必要. トランザクションデータの作成を行うクラス.
comの処理の時に実装した内容を抽象化して, 使用できるようにする. modelbased_correct_worksetとか。
Subject infoはクラス化する. 半径の計算はクラスに任せる. 半径計算の機能をコンポジションしてもいいかも.

#### プロセスの具体的なフロー

##### 基準フレーム取得プロセス

frame viewer toolで, 直立フレーム, 開始フレーム, 終了フレームを取得する.

##### 補正処理

1. correct poseのpickle読み込み.
2. pickleから, worksetファイルの作成.
3. 必要事項の記載確認処理.
4. メイン処理実行(以降詳細記載).
5. poseの読み取り. correct pickleから.
6. 基準フレームの取得, 長さ計算, オブジェクト生成.
7. 足首座標の計算処理, 固定位置かつ靴の大きさ, 足先端座標の使用.
8. 周囲径を元にした, 一部poseの奥行き補正. 処理を独立させて, movementかlist[Pose3D]で返す.
9. 腰の補正処理.
10. 補正後データからneckとwaist frontを計算.
11. csvデータに出力, movementオブジェクトに変換してpickleに保存.
